# cn-humanizer-academic

中文学术论文降 AI 痕迹的 Claude Skill,**专门针对 BERT 语义检测器**(知网 4.0+ / 维普 / PaperPass)。

## 它和 Humanizer-zh 有什么不同?

| 维度 | Humanizer-zh | 本 skill |
|---|---|---|
| **针对场景** | 通用中文写作 | 中文学术论文(毕业论文/期刊/综述) |
| **对抗目标** | 第一代统计检测器(困惑度/突发性) | 第二代 BERT 语义分类器 |
| **核心策略** | 24 种 AI 词汇模式识别 + 替换 | 段落级语义重构 + 论证方式重写 |
| **典型使用顺序** | 一轮:清扫词汇 | 二轮:深度重写 |

## 为什么需要它?

很多人用 Humanizer-zh 把 AI 率从 60% 降到 30%~40%,但 **30% 以下就降不动了**——因为知网/维普已经升级到 BERT 检测,**词汇替换对它没用**。

本 skill 解决的就是 BERT 抓的那部分:**段落整体的论述结构、句子间的流畅度、抽象 vs 具体的比例**。

## 安装(Claude Code)

```bash
git clone <你的仓库或本地路径> ~/.claude/skills/cn-humanizer-academic
```

或者直接把 SKILL.md 复制到:

```
~/.claude/skills/cn-humanizer-academic/SKILL.md
```

重启 Claude Code 后,在对话里说:

```
/cn-humanizer-academic 帮我改这段
[粘贴文本]
```

或者直接说:

```
帮我用语义层降低这段的 AI 痕迹
[粘贴文本]
```

## 使用建议

1. **第一轮**先用 Humanizer-zh 清扫词汇层
2. **第二轮**用本 skill 做语义层重构
3. **最后人工通读**——机器辅助永远不能完全替代人工

## 不能完全代劳的事

- **加私货**(你的实验细节、导师讨论、个人观察)——这是降 AI 痕迹最有效的手段,但只能你自己加
- **段落顺序大调整**——需要你对论文整体结构的判断
- **最终把关**——确保改完后专业术语没动、逻辑没断、文献引用还对

## 适用范围

✅ 中文毕业论文(本科 / 硕士 / 博士)
✅ 中文期刊论文
✅ 中文综述
✅ 中文技术报告
❌ 英文论文(BERT 中文版和英文版指纹不同,建议用原版 Humanizer)
❌ 营销文案 / 公众号文章(用原版 Humanizer-zh 即可)
