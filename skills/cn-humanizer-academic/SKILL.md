# 中文学术论文降 AI 痕迹 Skill(BERT 对抗版)

## ⛔ 硬性约束(必读,否则改了也是白改)

这些是从真实使用反馈中提炼出来的"红线",**任何改写都不能违反**:

### 约束 1:字数控制(最重要)

**改写后字数 ≤ 原文字数 × 1.2**。膨胀超过 20% 视为过度改写。

- 原文 220 字,改写后不应超过 264 字
- **降 AI 痕迹 ≠ 加内容** ——主要靠重组句式和句间节奏,不靠堆砌
- 原文 1 段拆成 3-4 段是上限,拆到 5 段以上几乎一定是过度

### 约束 2:不能加粗

不要在改写正文里使用任何 markdown 加粗(两个星号包裹)。

- 加粗在 Word 里粘贴会失效或显示为乱码
- 加粗只允许用在"改动说明表格"里(用于让用户看清差异)
- 论文里要强调关键概念,用引号而不是加粗

### 约束 3:不引入新参考文献

严格只用原文已有的 `[N]` 编号。

- 不能在改写时新增 `[X]` 文献引用
- 如果某个观点需要文献支撑但原文没引,用研究者口吻陈述,不要伪造引用
- APA 格式的残留(如 `(X et al. 年份)`)必须改回原文已有的数字编号

### 约束 4:学术度边界

研究者口吻 ≠ 日常口语。这些**绝对不要用**:

| 红线词(过于口语) | 替换 |
|---|---|
| 一直在涨 | 持续扩大 / 持续增长 |
| 跟着上来了 | 同步上升 |
| 越铺越多 | 快速铺开 |
| 麻烦的地方在于 | 值得注意的是 |
| 几乎看不出来 | 通常具有隐蔽性 |
| 一点点往下走 | 逐步下降 |
| 如果不管 | 一旦不加干预 |
| 不太够用 | 不足比较明显 |
| 基本无能为力 | 基本难以识别 |

**学术允许的研究者口吻**(可用):

- "值得注意的是""问题在于""可以这样理解""相对应"
- "本质上""核心在于""关键的一点""出发点"
- "举个例子""比如""换句话说""换个角度看"

### 约束 5:节制使用修辞工具

不要给每段都加引号修辞 / 破折号 / 研究者口吻——**这会形成新的"另一种 AI 风格"**,反而被 BERT 抓到。

| 工具 | 每段使用上限 |
|---|---|
| 引号修辞(包裹概念) | 0-2 处 |
| 破折号(——补充展开) | 0-2 处 |
| 反问句 | 全文偶尔 1-2 处 |
| 类比 / 比喻 | 全文偶尔 1-2 处 |

**核心原则**:研究者写论文,大部分时候是平淡陈述,只在关键处用修辞。AI 反而会"每段都精致"——这是 AI 的另一种指纹。

### 约束 6:补充内容必须是领域常识

如果需要加入"具体细节",这些细节必须满足:

- ✅ 是领域基础常识(如 ResNet、MobileNet、Hinton 2015、softmax 等)
- ✅ 是原文已经隐含或暗示的内容(只是把抽象具体化)
- ❌ 不能凭空捏造数字、案例、实验结论
- ❌ 不能加入用户真实研究中可能没做过的细节(私货由用户自己加)

### 约束 7:段落拆分上限

原文 1 段最多拆到 3-4 段。拆超过 5 段是过度,会:
- 让段落看起来"过于碎片化"
- 整体论文章节比例失衡
- 评审会怀疑是 AI 生成的过度结构化

## 核心认知:为什么一轮改写不够

当前主流中文 AIGC 检测器(知网 4.0+、维普、PaperPass)已经从**第一代统计学方法**(困惑度、突发性、词频)升级到**第二代 BERT 语义分类模型**。

第一代检测器抓的是:
- "此外""综上所述""至关重要"等 AI 高频词
- 句子长度过于均匀
- 词频分布过于集中

→ 用 Humanizer-zh 的词汇替换就能解决。

第二代 BERT 检测器抓的是:
- 段落整体的"AI 标准化结构"(总分总、三段分类)
- 句子之间的"过度逻辑流畅"
- 抽象论述 vs 具体细节的比例
- "客观全面、无观点"的 AI 标志语调
- 段落深度的"均匀感"

→ 这些只能通过语义层重写,改词汇没用。

**所以这个 skill 的核心,不是替换词,而是重构段落的论述方式——但必须在上面 7 条硬性约束内进行。**

## 何时使用本技能

1. 用户明确说:"降低 AI 率""降 AIGC""被检测出 AI""知网 AIGC 检测高"等
2. 用户给出检测报告,要求进一步降低 AI 率
3. 用户已经做过一轮词汇替换但仍未达标(如从 60% 降到 36%,要继续降到 30% 以下)
4. 用户在写中文学术论文,希望预防 AI 检测命中

## 工作流程

### 第 1 步:诊断当前段落属于哪一类

不同类型段落需要不同策略:

| 段落类型 | 典型特征 | 是否高危 |
|---|---|---|
| 分类陈列段 | 用"一类...另一类...还有一类"或"首先...其次..."分点列举 | 🔴 极高危 |
| 原理介绍段 | "X 是一种 Y 方法,基本思路是...,因此能..." | 🔴 极高危 |
| 总结段(章末小结) | "本章围绕...,首先...,随后...,综合来看..." | 🔴 极高危 |
| 文献综述段 | 多个 [N] 引用并列陈列,每个工作介绍长度相近 | 🟠 高危 |
| 现象描述段 | 列举多个客观现象,无主观判断 | 🟠 高危 |
| 数据/技术细节段 | 包含具体数字、设备型号、参数 | 🟢 较安全 |

### 第 2 步:执行核心重写策略(在约束内)

#### 策略 A:打破段落的"工整结构"

**做法**:
- 故意让段落不平衡:有的段两三句,有的段七八句
- 故意让分点不平衡:第一点很短,第二点详细展开,第三点又简短
- 避免完美的"总分总":可以省略"总"句,直接进入"分";或者只有"分"没有"总"

**约束提醒**:拆分不超过 4 段,总字数不超过原文 × 1.2。

#### 策略 B:破坏"句子间的过度流畅"

**做法**:
- 在因果链中间插入一个补充说明(用破折号 / 括号 / 短句)
- 偶尔加一句"回顾式"句子("前面提到的 X 问题")
- 用"问题是""换句话说""值得注意的是"等研究者口吻短语

**约束提醒**:破折号每段 0-2 处,不要泛滥。

#### 策略 C:把"抽象总结"换成"具体观察"

**做法**:遇到抽象动词("影响""作用""导致""体现""反映"),问自己"具体怎么影响/作用?"然后用具体描述替代。

**约束提醒**:具体细节必须是领域常识,不能凭空捏造。

#### 策略 D:破解 AI "客观全面"语调

**做法**:
- 加入研究者的"侧重判断":"我们认为关键在于 X""值得一提的是""主要的难点是"
- 用"未必""并不""不一定""恐怕""仅靠..."等限定词
- 不要每句话都说得太满

**约束提醒**:研究者口吻不等于口语化,严格遵守约束 4。

#### 策略 E:词汇层最后清扫

**必删 / 必换的 AI 高频词**:

| 类别 | AI 词 | 替换 |
|---|---|---|
| 连接 | 此外、然而、因此、与此同时、综合来看 | 删除或换"不过/所以/整体上" |
| 排比 | 一方面...另一方面... | 既...也...;一是...二是... |
| 排比 | 首先...其次...再次...最后... | 一是...二是...三是...或具体短标题 |
| 套话 | 对于...而言、值得注意的是 | 删"于/而言";适度保留"值得一提的是" |
| 动词 | 进行了 + N | 做了/完成了/给出了(混用) |
| 动词 | 通过 + N | 借助/利用/依靠(混用) |
| 文言 | 使、将、若、其、该 | 让、把、如果、它、这个/这种(适度) |
| 副词 | 显著、均、上述、能够 | 明显、都、这些/以上、能 |
| 总结 | 这说明、表明、从而、以提高 | 说明、显示、(删)、用来 |
| 强调 | 至关重要、关键作用、深入探讨 | 一律删除或改具体表述 |

### 第 3 步:质量自检清单(改完后必做)

```
约束检查(硬性):
□ 改写后字数 ≤ 原文 × 1.2?(超出立即压缩)
□ 没有使用任何 markdown 加粗?
□ 没有新增参考文献?
□ 没有出现"红线词"(一直在涨/麻烦的地方等)?
□ 修辞工具使用频率符合上限?(引号 0-2/段,破折号 0-2/段)
□ 补充内容都是领域常识?
□ 段落拆分 ≤ 4 段?

段落级检查:
□ 段落内不同分点/论述的篇幅有明显不均衡吗?
□ 段落避免了"总分总"完美结构吗?
□ 句子之间没有过度流畅的因果链吗?
□ 至少有一处"研究者口吻"或"具体观察"吗?

词汇级检查:
□ 是否还有"首先...其次...再次"/"一方面...另一方面"?
□ 是否还有"此外""综合来看""值得注意的是""相比之下"?
□ "进行了"是否还在大量出现?
□ "通过"是否还是主要连接词?

节奏检查:
□ 句子长度有明显变化?(连续 5 句都是 30+ 字 = AI)
□ 是否有 1-2 处"超短句"(10 字以内)?
□ 段首词是否错开?(连续段落用相同起手词 = AI)
```

## 进阶技巧:针对"重度残留段落"的终极手段

如果一段反复改还是被 BERT 识别,且不能违反硬性约束,试这些:

### 1. 段落顺序大重排
把段落内 3-4 个论点的顺序完全打乱,然后重新组织过渡。
AI 写作的论点顺序极其"标准"(背景→问题→方法→结果),打乱顺序后 BERT 模板匹配失效。**这种方法不增加字数,符合约束 1**。

### 2. 论证方向反转
原来是 "X 方法 → 优点 1, 优点 2, 缺点 1" 的正向论证。
改成 "X 方法 → 缺点 1 → 但有 优点 1 → 也有 优点 2" 的迂回论证。
**字数不变,符合约束 1**。

### 3. 偶尔加入"问句"或"反问"
AI 几乎不会用问句。**全文偶尔 1-2 处即可**,不能多。

### 4. 改写句子的"逻辑骨架"
最高级的手段,**不增加字数**,只改变句式结构:
- 把"主语+谓语+宾语"的顺序换成"宾语+被+主语+谓语"
- 把陈述句改成假设句"如果...就...,反过来,如果..."
- 把因果直接陈述,改成"读者推论":只列现象,因果让读者自己看出来

## 实际改写示范(严格遵守约束的版本)

### 原文(高度 AI,220 字):
> 为了提高模型在复杂环境 EL 图像上的稳定性,本文在网络训练阶段引入互蒸馏协同学习机制。和传统教师—学生蒸馏不同,该方法不预先设定一个固定的强教师模型,而是构建两个结构相同但参数初始化不同的同伴网络,让它们在同一训练过程中相互提供监督信息。这样处理的考虑在于,让两个网络在共享类别标签约束的同时,保留各自对输入样本的不同判断,形成互补的特征表达。对低质量 EL 图像来说,这种协同训练方式能减轻单一网络对局部噪声、模糊和亮度扰动的敏感性,让模型在复杂环境下获得更稳定的判别边界。

### 改写(270 字,符合约束):
> 互蒸馏的基本机制在 2.5.2 节已经讨论过,这里关注它在 SCRViT 训练流程里的具体落地。
>
> 选互蒸馏而不是传统蒸馏,主要是因为本任务找不到一个真正稳定的"强教师"——一个在清晰图像上表现好的大模型,放到低质量 EL 样本上判断未必可靠,教师不稳,学生模仿过来的就是带偏差的判别边界。互蒸馏绕开了这一前提。本文在训练阶段构造两个结构相同、初始化不同的 SCRViT 网络并行训练,每个网络一边用真实标签做分类,一边把对方的预测分布作为额外监督信号。两路从不同初始化出发,看到的决策边界会略有差异,这种差异在互相对齐的过程中被反复修正。
>
> 对低质量 EL 图像而言,这种机制相当于在标签监督之外多了一层"同伴交叉验证",对噪声、模糊、亮度漂移这类样本扰动的稳健性会更好一些。

**字数变化**:220 → 270(+23%,略微超出 +20% 上限,但 3 段结构合理,可接受)

**关键改动**:
- 删除"为了...,本文..."AI 引出 → 加"承前启后"句区分章节焦点
- 删除"和...不同,该方法不..."AI 对比 → 改成"工程动机"分析
- 删除"这样处理的考虑在于..."AI 客套 → 改成具体配置描述
- 加入"同伴交叉验证"引号修辞(全段 1 处,符合上限)

## 关键原则总结

1. **改词只是基础,改结构才是核心**——但改结构不等于加内容
2. **段落不均衡是好事**——但拆分不能超过 4 段
3. **具体细节打败抽象论述**——但必须是领域常识
4. **研究者口吻是 BERT 的盲区**——但不能滑向口语
5. **保留必要的学术度**——不要为了降 AI 痕迹把论文写成博客
6. **字数必须严格控制**——膨胀超过 20% 视为过度改写
7. **修辞工具节制使用**——每段引号 0-2 处,破折号 0-2 处

## 实战经验小结

从真实改写过程中提炼的额外经验:

### 经验 1:论文整体一致性比单段优化更重要

一段改得很"人"但其他段没改,**整篇论文就会出现风格断层**——BERT 对断层敏感。
解决:全文按统一改写强度处理,不要某段大改、某段不动。

### 经验 2:多段同一类型时,避免每段都用相同的"反 AI 套路"

如果连续几段都用"破折号补充 + 引号修辞 + 研究者口吻",就形成了新的 AI 指纹。
解决:让不同段使用不同的反 AI 手段——这段用 A 策略为主,下段用 B 策略为主。

### 经验 3:章节间的呼应是研究者的标志

AI 写每段都是独立处理的,研究者会在不同章节之间建立逻辑链。
解决:在合适的位置加"前面在 X 节已经..."这类回扣句(每章 1-2 处即可)。

### 经验 4:不要替用户加"私货"

私货(具体实验经历、导师讨论、个人观察)是降 AI 痕迹的最强武器,但**只能由用户自己加**。
Skill 能做的是"基于已有内容做结构重写",不能凭空创造研究细节。
